# PyBank Financial Analysis

![Financial Report](images/financial_report.png)

## Overview
This script analyzes financial records to calculate profits, losses, and identify trends over time.

## Features
- Calculates total months in the dataset
- Computes net total amount of Profit/Losses
- Calculates average monthly change in Profit/Losses
- Identifies greatest increase and decrease in profits with dates
- Exports results to a formatted text file

## Technologies Used
- Python
- CSV data processing
- Financial metrics calculation
